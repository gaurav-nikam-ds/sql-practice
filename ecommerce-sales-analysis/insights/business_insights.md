# Business Insights

This file is intended to be completed after running the SQL analysis.

## Questions to Answer

1. Which city generated the highest revenue?
2. Which customer generated the highest spending?
3. Which product sold the highest quantity?
4. Which category generated the highest revenue?
5. Which product generated the highest estimated profit?
6. Which payment method was used most often?
7. What percentage of orders were cancelled or returned?
8. Which customer segment generated the most revenue?
9. Which month generated the highest revenue?
10. Which customers made repeat purchases?

## Business Recommendations

Add recommendations only after checking the actual SQL results. Each recommendation should be connected to a finding.

Example format:

- Finding: [result from SQL]
- Business implication: [why it matters]
- Recommendation: [action the business could take]
