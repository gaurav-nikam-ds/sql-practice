# Business Questions

## Purpose

This project is not only a collection of SQL queries. The analysis is organized around business questions and the SQL concepts required to answer them.

## Current Version

### Sales & Order Performance
1. How many customers, products and orders are in the dataset?
2. How many units were sold through delivered orders?
3. What is the total delivered revenue?
4. What is the average delivered order value?
5. How many orders were cancelled or returned?
6. What percentage of orders were cancelled or returned?

### Payment Analysis
7. Which payment method is used most often?
8. Which payment method generates the most delivered revenue?
9. How many units were sold through each payment method?

### Customer Analysis
10. Which customers are repeat purchasers?
11. Which customers generated more than 5,000 in revenue?
12. Which customers generated the highest revenue?
13. Which customers placed more than 2 delivered orders?
14. Which customers generated more than 8,000 revenue and placed at least 2 delivered orders?

### Order Analysis
15. What is the highest-value delivered order?
16. Which orders contain multiple units?
17. Which delivered orders occurred between June and September 2025?

## Business Analysis Process

For each question:

**Business Question → Required Data → SQL Concept → Query → Result → Business Meaning**

## Current SQL Skills Applied

- SELECT / FROM
- WHERE
- AND / OR / NOT
- IN
- BETWEEN
- LIKE
- DISTINCT
- ORDER BY
- LIMIT
