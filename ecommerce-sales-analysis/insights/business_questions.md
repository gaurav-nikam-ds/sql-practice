# Business Questions

This file lists the questions covered by the current SQL project, using the concepts I have practised so far.

## Sales and Order Performance
1. How many customers, products and orders are in the dataset?
2. How many units were sold through delivered orders?
3. What is the total revenue from delivered orders?
4. What is the average delivered order value?
5. How many orders are delivered, cancelled and returned?
6. What percentage of orders were cancelled or returned?
7. What is the highest-value delivered order?
8. Which delivered orders contain multiple units?
9. Which delivered orders fall within a selected date range?

## Payment Analysis
10. Which payment method is used most often for delivered orders?
11. How much delivered revenue is generated through each payment method?
12. Which payment methods have delivered revenue above ₹20,000?
13. How many units are sold through each payment method?

## Customer Analysis
14. Which customer IDs placed more than one delivered order?
15. Which customer IDs generated the highest delivered revenue?
16. Which customer IDs generated more than ₹5,000 in delivered revenue?
17. Which customer IDs generated more than ₹8,000 and placed at least two delivered orders?
18. Which customer IDs purchased more than four units?

## Data Handling and String Functions
19. How can missing values be displayed with a default value using COALESCE?
20. How can customer names be converted to uppercase or lowercase?
21. How many characters are in each customer name?
22. How can names be shortened, trimmed, modified or combined for reporting?

## Scope

The current project uses the SQL concepts practised through string functions. It does not include JOINs. Analysis requiring product names, category-level revenue or customer names matched to order transactions is not included in this version because it requires JOINs.
